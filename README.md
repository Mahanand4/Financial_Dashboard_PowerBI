 Financial Dashboard – Power BI

## Project Description

An interactive financial dashboard developed using Microsoft Power BI to analyze revenue, profitability, budget vs. actual performance, cash flow, receivables, payables, and product/service performance.

## Key Features

- Revenue and profit analysis
- EBITDA and net cash KPIs
- Budget vs. actual analysis
- Product/service performance
- Receivables and payables aging
- Cash-flow analysis
- Interactive filters and drill-downs
- Monthly financial trend analysis

## Tools Used

- Microsoft Power BI
- Power Query / Data Preparation
- DAX

## Project Deliverables

- Power BI Dashboard
- Project Documentation
- Dashboard Screenshots
